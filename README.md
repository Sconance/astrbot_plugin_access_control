# AstrBot 消息访问控制


通过群白名单、用户忽略名单、私聊开关和指定 QQ 的 @ 过滤，管理机器人可以响应的群聊、用户及消息。


## 功能特性


- **群白名单**：只处理允许群聊中的消息。
- **用户忽略名单**：禁止指定用户触发机器人。
- **私聊控制**：选择是否处理私聊消息。
- **@ 过滤**：群聊消息实际 @ 到指定 QQ 时停止处理。
- **管理员管理**：通过聊天指令启用或禁用用户权限，修改结果保存到配置。
- **实时拦截**：不符合规则的普通消息停止处理，不发送拦截提示。


通用版默认关闭访问控制，群号和 QQ 号均为空。请先配置允许的群聊，再开启总开关。


## 配置说明


在 AstrBot WebUI 的插件设置页调整：


| 配置项 | 说明 |
| --- | --- |
| `enabled` | 访问控制总开关，关闭后不执行消息过滤 |
| `allowed_groups` | 允许响应的 QQ 群号，每项填写一个群号 |
| `allow_private` | 是否允许私聊 |
| `blocked_sender_enabled` | 是否启用发送者忽略名单 |
| `blocked_sender_qqs` | 要忽略的发送者 QQ 号 |
| `blocked_at_enabled` | 是否启用群聊中指定 QQ 的 @ 过滤 |
| `blocked_at_qq` | 被过滤的 @ 对象 QQ 号 |


## 使用说明


### 管理员命令


仅 AstrBot 管理员可以使用以下管理命令。可以 @ 成员，也可以直接填写 QQ 号；指令可直接发送，也兼容 `/` 前缀。


| 指令示例 | 功能 |
| --- | --- |
| 访问控制帮助 | 查看插件功能、管理命令及用法 |
| 查看禁用名单 | 查看禁用 QQ 号、访问控制总开关和用户黑名单状态 |
| 权限禁用 @成员 | 将成员加入忽略名单并启用发送者过滤 |
| 权限启用 @成员 | 将成员移出忽略名单 |
| 禁用 1234567 | 禁用指定 QQ 的触发权限 |
| 启用 1234567 | 恢复指定 QQ 的触发权限 |
| 1234567 启用 | 恢复指定 QQ 的触发权限 |


### 工作原理


开启访问控制后，插件会先检查发送者是否在禁用名单中，再根据消息类型判断是否允许继续处理：


- **私聊消息**：由“允许私聊”开关控制。
- **群聊消息**：仅允许群白名单中的群聊；如果开启了 @ 对象过滤，群聊消息中 @ 到指定 QQ 的消息也会被拦截。


被拦截的消息不会继续触发机器人功能，也不会收到拦截提示。关闭访问控制后，插件不再过滤普通消息。


### 权限管理说明


管理员命令不受上述消息过滤规则限制，但只有 AstrBot 管理员可以使用。


- **禁用用户**：将指定 QQ 加入禁用名单，并开启用户黑名单。若访问控制总开关处于关闭状态，名单会保存，待总开关开启后生效。
- **启用用户**：将指定 QQ 从禁用名单中移除。该用户的消息仍需符合群白名单、私聊开关和 @ 对象过滤设置。
- **重复操作**：会提示用户当前的名单状态；配置没有变化时不会重复保存。


名单中的空项、首尾空格和重复项会自动清理。


## 安装方法


在 AstrBot WebUI 中选择「插件」→「添加插件」→「从链接安装」，填写仓库地址：https://github.com/Sconance/astrbot_plugin_access_control 。安装完成后启用插件并配置访问规则。


本插件无需额外第三方依赖，支持 aiocqhttp（OneBot v11）平台。


## 注意事项


- 总开关开启时，群白名单为空会拦截所有群聊普通消息。
- 用户忽略名单同时影响群聊和私聊。
- @ 过滤仅适用于群聊，检测实际消息组件中的 QQ 号，不匹配昵称或普通文字。
- 不能修改机器人自身的用户权限，也不能禁用当前操作者。
- 管理员的普通消息仍受过滤规则限制。
- 配置持久保存；聊天指令修改名单后无需重启。
- 关闭总开关不影响管理员权限管理指令的使用。
